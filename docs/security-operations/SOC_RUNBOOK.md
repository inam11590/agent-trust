# Security Operations Center (SOC) Standard Operating Procedures

## Purpose
This document provides step-by-step guidance for security analysts triaging alerts generated by the AgentTrust Security Operations Center.

---

## General Alert Triage Workflow

1. **Acknowledge Alert**:
   - Navigate to /dashboard/security/alerts.
   - Select the open alert and click **Acknowledge**.
   - This records your analyst identity and timestamp, indicating active investigation.

2. **Inspect Context & Timeline**:
   - Review the alert details drawer. Note the ule_id, affected gent_id, gateway_id, and irst_seen_at / last_seen_at timestamps.
   - Click **View Related Events** to open the chronologically sorted investigation timeline.

3. **Follow Correlation IDs**:
   - Copy the correlation_id from the triggering event.
   - Filter by this correlation_id in the Event Explorer (/dashboard/security/events) to trace the end-to-end request from client to gateway to authorization decision.

4. **Determine Containment Actions**:
   - If an Agent's signing key is compromised: Revoke the key immediately (/dashboard/agents/{id}).
   - If an Enterprise Gateway is malfunctioning or compromised: Revoke the Gateway token/certificate (/dashboard/gateways/{id}).
   - If an ATC credential is being abused: Revoke the credential (/dashboard/trust-registry/credentials).
   - If an ongoing attack is detected: Enable stricter risk engine policies.

5. **Resolve Alert**:
   - Once containment and remediation are complete, click **Resolve**.
   - Enter a detailed resolution note describing findings and remediation steps.
